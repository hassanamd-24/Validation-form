# Interactive Signup Validation Form

A clean, dark-themed signup interface featuring robust frontend validation. Built from scratch to demonstrate secure and intuitive client-side data handling.

🔗 **[Live Demo Link](https://hassanamd-24.github.io/validation-form/)**

## ✨ Features
* **Real-time Validation:** Dynamic feedback on name input, email formatting, and password strength requirements.
* **Password Toggle:** Built-in visibility eye icon to switch between hidden and plain text characters.
* **Responsive UI:** Clean, centered container design optimized for various device viewports.
* **Modern Aesthetic:** Dark-mode styling with high-contrast inputs and call-to-action button.

## 🛠️ Tech Stack
* **HTML5** - Structured form elements and input semantic types.
* **CSS3** - Custom dark layout, layout alignment, and interactive UI styling.
* **JavaScript (ES6+)** - Event-driven form validation algorithms and visibility toggles.
